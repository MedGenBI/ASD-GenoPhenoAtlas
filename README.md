# ASD-GenoPhenoAtlas

## Overview

This repository contains the source code and analysis scripts for the study **"Genotype-phenotype atlas dissects autism heterogeneity and informs gene prioritization"**. It provides a comprehensive framework for constructing a high-resolution genotype-phenotype association atlas in Autism Spectrum Disorder (ASD) and implements the Gene-centric Polyphenotypic Score (GPS)—a novel quantitative metric designed to aggregate phenotype signals and predict carrier propensity for pathogenic variants.

## Key Components:

- **Association analysis**: Scripts for gene-based genotype-phenotype association analysis and post-processing.
- **GPS**: Full implementation of the GPS algorithm, including parameter optimization and performance evaluation.
- **Visualization**: Code to reproduce the major figures presented in the manuscript.

## Data

All raw genetic and phenotypic data for the SPARK cohorts are available upon request from [SFARI Base](https://base.sfari.org/). The full variant discovery, quality control, annotation, and other related procedures were conducted using public softwares as fully detailed in the manuscript.
